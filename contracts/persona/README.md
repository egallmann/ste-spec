# Persona contracts (draft)

**Status:** Draft / pre-normative. This folder sketches Persona as Context
Selection Policy contracts for MVC evolution experiments. Until promoted by ADR
and indexed in the cross-component contract inventory, consumers must not treat
this shape as stable interchange.

A Persona is a named role policy, not biography. It declares required and
optional Context Domain requirements, traversal objectives/preferences,
projection preferences, and rationale.
